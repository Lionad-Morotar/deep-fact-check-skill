# 深度事实核查分析技能

执行深度事实核查与认知偏见分析，识别信息操控手法，提供置信度分层评估与可溯源的修正建议。

## 理念

在信息爆炸的时代，真相往往被选择性呈现、情绪化修辞和权威误用所遮蔽。此技能不仅验证"是否属实"，更深入分析"如何被呈现"与"为何如此呈现"，帮助用户穿透信息迷雾，形成基于证据的判断。


```plaintext

```

## 核心能力

- **三层事实模型**：区分经验事实（L1）、解释框架（L2）、价值判断（L3）
- **七宗罪检测**：识别断章取义、选择性报道、时间差操纵、虚假类比、数字游戏、因果混淆、权威误用
- **多源三角测量**：并行搜索证实性、证伪性、竞争性框架证据
- **贝叶斯置信度**：基于证据质量赋予概率化置信度，诚实面对不确定性
- **作者偏见分析**：识别预设立场、选择性模式、语言特征

## 工作流程

1. **认知解构与提取**：使用 SIFT 原则（Stop-Investigate-Find-Trace）提取最小可验证单元
2. **多源三角测量与竞争性假设**：生成至少 3 个竞争性假设进行证伪检验
3. **深度对比与误导机制分析**：四维对比矩阵（事实层/语境层/时间层/评价层）
4. **置信度分层与认知边界标注**：贝叶斯后验概率 + 认识论状态标注
5. **生成结构化核查报告**：金字塔模型（执行摘要/详细发现/方法论）

## 输出格式

报告包含以下部分：

| 章节 | 内容 |
|------|------|
| 执行摘要 | 可信度评级、核心结论、关键发现速览 |
| 详细发现 | L1 事实验证、L2 框架争议、L3 价值分析 |
| 信息操控识别 | 七宗罪检测、操控机制解构 |
| 作者偏见分析 | 预设立场、选择性模式、客观性评分 |
| 证伪条件 | 可能推翻当前结论的新证据 |
| 使用建议 | 针对不同受众的引用建议 |

## 信源权威性评估

| 等级 | 类型 | 可信度权重 |
|------|------|-----------|
| T1 | 原始数据发布者（财报、政府统计、原始论文） | 90% |
| T2 | 权威专业媒体（Reuters, Bloomberg, Nature, 财新） | 75% |
| T3 | 行业分析/智库（Gartner, McKinsey, Pew Research） | 60% |
| T4 | 评论/社论/社交媒体 | 30% |
| TX | 匿名/无法溯源 | 0% |

## 伦理声明

本技能旨在提升信息质量，不构成对原文作者的人身攻击或对其观点的全面否定。重点在于**如何更准确地呈现事实**，而非**证明作者错误**。最终判断权在于用户，建议结合人工复核，特别是对涉及重大决策的内容。
